# Cloud Hosting Providers

## Digital Ocean

* App Platform starts at $0/month
* App Platform allows you to [deploy from a container registry](https://www.digitalocean.com/docs/app-platform/how-to/deploy-from-container-registry/).  
Supported registries include:
  * [DigitalOcean Container Registry](https://www.digitalocean.com/products/container-registry)
  * Docker Hub
  * GitHub Container Registry
* DigitalOcean Container Registry [DOCR]
  * Has a free tier that provides 1 repository (Can multiple images be stored in a single repository?)
  * It's a private registry
  * Free tier (of DOCR) is limited to 500MB
